# Simpli-FI Family public-route release gate

Status: **HOLD — local contract proven; production hosting unverified**

Last updated: July 15, 2026

The files in this repository establish the public Family pages and the Apple App Site Association content. They do not prove that the live origin serves the routes, redirects, MIME types, caching, or security headers Apple and the invitation flow require.

## Required production contract

- `https://simpli-fi-os.com/family/`, `/family/support/`, `/family/privacy/`, and `/family/join/?token=<synthetic-probe>` return direct `200 text/html` responses.
- Slashless aliases redirect only to the corresponding trailing-slash URL. The join redirect preserves the query exactly.
- `https://simpli-fi-os.com/.well-known/apple-app-site-association` returns a direct `200` with no redirect, `Content-Type: application/json`, and an uncompressed body smaller than 128 KB.
- The AASA detail binds only `N8J5KA7B3N.com.simplifi.familyos` to `/family/join/` with the exact query rule `{ "token": "*" }`.
- The invitation response should advertise `Referrer-Policy: no-referrer` and private or no-store caching. The edge should also advertise `X-Content-Type-Options: nosniff` and a response-header CSP that prevents framing.

## Hosting decision still required

The checked-in Vercel configuration rewrites Apple’s required extensionless URL to the canonical JSON source and adds release security headers. This still must not be labeled production-AASA-ready until the direct public response passes the production verifier.

Before live approval, place these routes behind a header-capable static host or verified edge/proxy rule. Keep the canonical paths and AASA content unchanged unless the app entitlement and release verifier are updated in the same reviewed change.

## Proof commands

Local, dependency-free contract:

```bash
npm test
npm run build
```

Approved deployment only, using a synthetic token probe generated by the verifier:

```bash
npm run verify:family:production -- https://simpli-fi-os.com
```

Live associated-domains approval remains blocked until the production command exits successfully and its response-header warnings are reviewed. Do not use a real invitation token for release verification.
